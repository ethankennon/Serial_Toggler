This is intended to send quick, simple serial commands to a USB serial device and time the responses.

The curent intended target is https://github.com/ethankennon/ATMega2560-USB-Ser which controls a relay based on these serial commands.

This project uses the https://github.com/mik3y/usb-serial-for-android/tree/master library to handle USB communication. Their license can be found in NOTICES.txt
